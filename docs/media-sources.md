# Gestaltung und Medien

Die Gold-/Petrol-Gestaltung wird eigenständig umgesetzt. Das vom Nutzer gezeigte ForeverFishing-Bild dient als Stilreferenz und wird nicht mitgeliefert.

- Lua-Rahmen, Ornament-Geometrie, Texte und Farbgestaltung: eigene Implementierung unter der MIT-Lizenz dieses Projekts.
- SVG-Illustrationen und CSS-Oberfläche der Browservorschau: eigene Implementierung unter MIT.
- Die Spieloberfläche referenziert vorhandene WoW-Symbole über Textur-IDs und vorhandene WoW-Schriften über den Client. Blizzard-Grafiken und -Schriftdateien werden nicht kopiert oder ausgeliefert. Deren Rechte werden nicht von der MIT-Lizenz erfasst.
- Kein Code und keine eigenen Medien aus ForeverFishing oder ForeverXPBar übernommen.
